# 🌍 Travel Management System

A database-driven web application developed using **PHP, MySQL, HTML, CSS, and Bootstrap**. The Travel Management System is designed to provide an organized platform for displaying travel destinations and packages while allowing users to register, log in, view package details, and submit travel enquiries.

---

##  Project Overview

The **Travel Management System** is a web-based application that simplifies the process of managing and presenting travel-related information.

The system provides users with information about different destinations and travel packages through a simple and user-friendly interface. It also includes user registration, authentication, package details, and enquiry functionality.

This project was developed as a PHP and MySQL-based web application with Bootstrap for the user interface.

---

##  Features

### 👤 User Features

- User registration
- User login and authentication
- View travel destinations
- Browse travel packages
- View package details
- Submit travel enquiries
- Browse travel information through an organized interface

### 🧳 Travel Package Features

- Display available travel packages
- Package categories
- Package details
- Destination information
- Travel-related images
- Organized package navigation

### 🎨 Interface Features

- Responsive web interface
- Bootstrap-based design
- Navigation menu
- Image slider
- Destination images
- Package browsing interface
- Simple and user-friendly layout
